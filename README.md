# 车辆防碰撞预警系统嵌入式项目

基于 STM32F103C8T6 和标准外设库（SPL）的嵌入式项目，通过 HC-SR04 获取距离，根据距离调整蜂鸣器的鸣叫节奏。接入 MPU6050 采集加速度数据实现碰撞检测。最后接入 OLED 屏幕实现数据的采集。

## 软件工作流程

1. `BSP_Init()` 初始化毫秒时基、蜂鸣器和 HC-SR04 所需硬件。
2. 主循环持续调用 `Hcsr04_TaskHandle()`，推进测量状态。
3. TIM2 中断调用 `Hcsr04_IrqHandle()`，记录回波上升沿与下降沿并计算距离。
4. 主循环通过 `Hcsr04_GetDistance()` 获取最近一次有效距离。
5. 根据距离设置停鸣间隔，并调用 `Buzzer_Flash()` 推进蜂鸣器状态。

HC-SR04 等待回波及测量间隔采用状态机；TRIG 脉冲使用微秒级短时阻塞延时。蜂鸣器通过保存阶段和起始时间，在多次调用间完成鸣叫、停鸣切换。

### 当前报警规则

| 距离 | 行为 |
| --- | --- |
| 小于 2 cm，或当前返回值超出 200 cm | 关闭蜂鸣器 |
| 2～10 cm | 每次鸣叫 50 ms，停鸣 50 ms |
| 大于 10 cm 且不超过 200 cm | 每次鸣叫 50 ms，停鸣间隔随距离从 50 ms 增至 950 ms |

此处调整的是鸣叫节奏。距离与停鸣间隔的映射见 `User/main.c`。

### 共享 I²C 设计

- OLED 和 MPU6050 各有一个固定消息槽。
- 每槽最多保存 32 字节，并记录长度、传输索引、读写类型及完成时间等信息。
- 设计上由发送 / 读取接口提交任务，由 `I2cBus_TaskHandle()` 推进总线通信。
- 当前已定义结构体、状态与接口，实际任务提交和通信流程尚未完成。

## 编译与下载

1. 安装 Keil µVision 5，并准备工程所用的 ARM Compiler 5 和 STM32F1 器件支持包。
2. 打开根目录的 `Project.uvprojx`。
3. 选择 `Target 1`，检查编译器及 STM32F103C8 器件配置。
4. 使用 **Rebuild** 编译工程，检查错误与警告。
5. 在 **Options for Target → Debug** 中确认实际使用的调试器和下载配置。
6. 连接开发板，下载程序后运行或进入调试。

当前工程未启用 HEX 文件输出；如需 HEX，可在 **Options for Target → Output** 中启用。

## 测试方法

1. 按引脚表连接 HC-SR04 和蜂鸣器。
2. 在调试器中观察 `main()` 内的 `distance_cm` 与 `gap_ms`。
